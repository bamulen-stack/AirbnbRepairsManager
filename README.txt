Important:
A PWA can be installed by Chrome only when served from HTTPS (or localhost), not directly from the phone's Files app.
After installation, this app works offline.

Before moving from the old file-based version:
1. Open the old v5 FIXED.
2. More > Export Backup.
3. Install/open the PWA.
4. More > Restore Backup and select the backup file.
